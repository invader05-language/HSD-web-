# 活动报名闭环 QA 覆盖

## 已覆盖的代码级场景

- 共用报名模板：字段类型、稳定字段 ID、必填项、选项去重、数字/文本/日期/电话校验和多选上限。
- 模板生命周期：草稿版本、发布版本、乐观锁冲突，以及活动首次开放时绑定已发布修订。
- 报名生命周期：登录账号身份只读、服务端答案校验、唯一报名、取消、同一记录重新报名、审核决定和版本递增。
- 管理名单：中心权限、姓名/学号搜索、状态筛选、服务端分页、详情读取和按筛选条件导出。
- CSV 安全：UTF-8 BOM、字段值转义、公式前缀中和、安全文件名；导出只记录审计元数据，不记录答案内容。
- 自动化链路：活动报名开启事件继续走现有 outbox，过期关闭与手动截止时间覆盖保持一致。
