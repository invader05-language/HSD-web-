# 资源详情、媒体专题与考核结果前端设计

日期：2026-07-29  
产品：白云 HSD 开发者部落  
实现状态：Nuxt 4 / Vue 3 / TypeScript 前端已实现；后端、数据库、对象存储暂不接入

## 1. 目标

本轮补齐三个公开页面体系中的交互断点，并增加一个个人信息入口：

1. 资源中心的列表项可以进入真实的站内详情页，并根据资源类型呈现明确的阅读、预览、下载或登录动作。
2. 媒体画廊的专题卡片可以进入专题详情页，以全幅照片、暗层说明和灯箱浏览呈现精选作品。
3. 部落介绍底部四个中心继续整卡进入各自详情页，并加入回归验收。
4. 顶部导航新增“考核结果”；该入口属于个人信息，未登录时先进入登录页，登录后进入考核结果占位页。

## 2. 全局约束

- 主要验收对象是 `1440px` 桌面 Web。
- 延续深红、近黑、暖白/冷灰、克制边框和大留白的既有设计基调。
- 不使用用户提供的招新海报、参考截图或未授权照片作为网站素材。
- 当前不开发后端、数据库、CMS、对象存储或真实文件下载接口。
- 当前不虚构考核成绩、排名、评语、通过状态或数据库字段。
- 页面修改必须同步 PRD、变更记录、验收标准和视觉原型。

## 3. 信息架构

### 3.1 新增路由

| 路由 | 页面 | 权限 |
| --- | --- | --- |
| `/resources/:slug` | 资源详情 | 公开浏览；内部资料可按需登录确认身份 |
| `/gallery/:slug` | 媒体专题详情 | 公开 |
| `/assessment-results` | 考核结果 | 登录后访问 |

### 3.2 顶部导航

在现有“资源中心”和“加入我们”之间增加“考核结果”。

- 未登录点击：跳转 `/login?redirect=%2Fassessment-results`。
- 登录成功：继续进入 `/assessment-results`。
- 已登录点击：直接进入 `/assessment-results`。

导航仍使用单层结构。桌面端需要在 1440px 下保持完整、无重叠和无横向溢出。

## 4. 资源中心

### 4.1 列表行为

现有 `/resources` 保留分类筛选、结果数量和分页外观。所有资源条目不再使用页内锚点，统一进入 `/resources/:slug`。

列表动作按资源状态显示；当前文件均未接入，因此目录不承诺登录后即可下载：

- `阅读正文 →`
- `文件暂未接入 →`
- `该版本已下线 →`
- `前往外部网站 ↗`

列表点击本身只进入详情页，不直接触发浏览器下载。

### 4.2 资源类型

资源详情使用统一页面骨架，并按类型调整主要操作：

| 类型 | 详情页行为 |
| --- | --- |
| 网页 | 在站内详情页显示可阅读正文 |
| PDF | 显示文件信息、预览区域和下载动作 |
| DOCX | 显示文件说明、版本信息、PDF 预览动作和 DOCX 下载动作 |
| ZIP | 显示内容清单；未登录时主要动作跳转登录，登录后显示下载动作 |
| 外部链接 | 明确标记外部网站，并使用新窗口打开 |

当前没有真实文件和接口，因此所有需要文件的按钮显示“文件暂未接入”，保持不可用状态并解释原因。不得创建虚假文件或触发空下载。

### 4.3 页面结构

资源详情页按以下顺序组织：

1. 顶部导航
2. 面包屑
3. 资源眉题、H1 和简介
4. 文件信息面板：格式、大小、版本、更新时间、权限
5. 主要动作区
6. 资源说明或网页正文
7. 使用范围或内容清单
8. 版本记录
9. 相关资源
10. 页脚

### 4.4 状态

- 未知 slug：返回 HTTP 404。
- 文件未接入：保留详情信息，按钮不可用，显示“文件暂未接入”。
- 文件已下线：保留版本与说明，显示“该版本已下线”。
- 内部资源未登录：在“文件暂未接入”按钮保持禁用的同时，提供登录查看下载权限入口并携带当前详情页作为续接地址；登录后隐藏登录提示，但未接入状态不变。
- 外部链接：按钮文本和图标明确说明会离开本站。

## 5. 媒体画廊

### 5.1 列表行为

`/gallery` 继续按活动摄影、海报设计、短视频和人物专访筛选。每张作品卡改为可点击的专题入口，统一进入 `/gallery/:slug`。

专题列表不是单张照片瀑布流，而是对相册、视频专题或人物内容的编辑部式索引。

### 5.2 专题详情布局

专题详情采用已确认的 A 方案：

1. 面包屑
2. 专题眉题、H1、简介
3. 类型、时间、公开数量和创作团队
4. 一张大比例主图
5. 两张次图组成右侧纵向区域
6. 后续照片使用非对称两列编辑部网格
7. 加载数量说明和“继续加载 12 张”
8. 相关专题与页脚

照片直接铺满整个图片区，不在图片内部增加灰色框或第二层素材容器。照片上覆盖从透明到深色的暗层，标题、拍摄场景和说明文字直接叠在图片上。

当前未提供可用于正式网站的授权照片，因此生产页面使用全幅品牌素材占位面，不使用参考截图或随机人物照片。占位面必须保持最终图片的宽高比例、暗层和文字位置。

### 5.3 灯箱

点击照片打开灯箱：

- 显示大图、标题、说明和当前序号。
- 支持上一张、下一张和关闭。
- 支持键盘 `ArrowLeft`、`ArrowRight` 和 `Escape`。
- 首尾切换不循环，禁用不可用方向。
- 打开灯箱后焦点进入关闭按钮；关闭后焦点返回原照片。
- 页面背景禁止滚动。

当前前端使用占位媒体验证灯箱行为；正式图片地址以后由对象存储字段提供。

### 5.4 图片承载边界

后端阶段采用以下边界，本轮只在文档中固定，不接入服务：

- 数据库只保存标题、说明、作者、宽高、排序、授权状态和图片地址等元数据。
- 图片和文件二进制放对象存储，通过 CDN 分发。
- 公开页面使用缩略图和 Web 展示图；原始高清照片单独归档。
- 每个专题默认公开精选 `12–30` 张，不把全部原片上传到公开网站。
- 页面每次加载 `12` 张，图片进入视口前不加载大图。
- 未授权照片不得进入公开数据。

### 5.5 状态

- 未知 slug：返回 HTTP 404。
- 无公开作品：显示专题说明和“该专题暂无公开作品”，并提供返回画廊入口。
- 图片加载失败：保留原始宽高比例，显示同尺寸品牌降级面。
- 灯箱图片失败：保留标题和说明，允许继续查看前后图片。

## 6. 部落介绍四中心入口

`/about` 底部“四个中心，平等协作”保留四张整卡链接：

- `/centers/baize-development`
- `/centers/new-media`
- `/centers/tuowei-planning`
- `/centers/talent-development`

卡片在未 hover 时显示“查看中心详情 →”。整卡可点击，键盘可聚焦。回归测试需要从 `/about` 实际点击一张卡进入对应中心，而不只检查 `href`。

## 7. 考核结果

### 7.1 权限

考核结果属于个人数据，不能公开浏览。

- 全局认证中间件保护 `/assessment-results`。
- 未登录访问时跳转登录页，并保存续接地址。
- 登录成功后返回考核结果页。
- 退出登录后再次访问需要重新登录。

### 7.2 当前页面

后端和数据库字段尚未确定，本轮只实现稳定的任务页面：

1. 顶部导航和当前栏目状态
2. 独立任务页头
3. 眉题 `Assessment Results`
4. H1 `考核结果`
5. 状态说明：`考核数据暂未接入`
6. 补充说明：数据接入后将根据已确认的后端字段设计展示结构
7. 返回成员空间和返回首页入口

页面不得显示虚构分数、评级、排名、评语、考核周期或通过状态。

## 8. 前端模块边界

- `app/data/resources.ts`：资源类型、Mock 条目和资源解析函数。
- `app/data/gallery.ts`：专题、媒体条目和专题解析函数。
- `app/pages/resources.vue`：资源列表。
- `app/pages/resources/[slug].vue`：资源详情。
- `app/pages/gallery/index.vue`：专题列表。
- `app/pages/gallery/[slug].vue`：专题详情与灯箱状态。
- `app/pages/assessment-results.vue`：受保护的考核结果占位页。
- `app/data/site.ts`：顶部导航。
- `app/utils/access-policy.ts`：考核结果和内部下载的登录边界。

资源与画廊数据不放入 Pinia。Pinia 继续只管理登录演示状态。

## 9. 验收

### 9.1 资源

- 五种资源类型均进入站内详情，不从列表直接下载。
- 资源详情的格式、权限、状态和主要动作一致。
- 未接入文件不会触发虚假下载。
- 内部资源可登录并返回原详情页确认成员身份；当前文件未接入时，登录前后均保持禁用且不提供下载。
- 未知资源返回 404。

### 9.2 画廊

- 所有专题卡可以进入详情页。
- 照片铺满版面，没有内部灰色素材框。
- 暗层上的标题和说明在桌面端清晰可读。
- 灯箱支持鼠标、键盘、焦点恢复和背景滚动锁定。
- 每次加载 12 张；空状态和图片失败状态完整。
- 未知专题返回 404。

### 9.3 中心与考核

- `/about` 四张中心卡均可整卡进入对应详情页。
- 顶部导航显示“考核结果”。
- 未登录点击“考核结果”进入登录页。
- 登录后继续进入 `/assessment-results`。
- 考核结果页不出现任何虚构数据库字段。

### 9.4 全站

- 1440px 无横向溢出。
- 新增交互均有可见键盘焦点。
- 正文字号不小于 16px。
- 页面标题、H1、空状态和 404 状态语义正确。
