# 白云 HSD 开发者部落管理端设计规格

- 日期：2026-07-30
- 状态：已确认，待制定实现计划
- 主要验收视口：1440px 桌面 Web
- 管理员视角：联盟总负责人
- 技术边界：与用户端共用同一个 Nuxt 工程，使用独立管理路由和布局

## 1. 目标

基于已实现的用户端官网、成员空间、结果中心、招新报名、项目、活动、人员名录、媒体画廊和资源中心，反向建立完整的管理端信息架构与桌面原型。

管理端需要让联盟总负责人完成以下工作：

1. 查看当前最重要的待办和业务状态。
2. 管理招新批次、报名人员、考核结果与结果发布。
3. 管理预备成员、正式成员、核心人员、中心归属和公开荣誉。
4. 管理项目、活动、活动报名和赛事记录。
5. 管理首页快讯、新闻公告、Banner、帮助内容和首页推荐。
6. 管理图片、画廊专题、学习资料、文件版本与访问权限。
7. 管理管理员账号、角色权限、操作日志和回收站。

本阶段交付可点击的前端 Mock 原型，不连接真实数据库、对象存储或后端 API。

## 2. 架构边界

### 2.1 单工程、双布局

用户端与管理端共用一个 Nuxt 工程：

- 用户端使用默认官网布局和公开导航。
- 管理端使用 `/admin/**` 路由命名空间和独立 `admin` 布局。
- 两端共享品牌设计令牌、登录会话、领域类型、表单校验规则和未来 API 契约。
- 管理端导航不得混入公开官网。
- 用户端展示组件与管理端业务组件不强制复用。

### 2.2 权限边界

首版原型以联盟总负责人视角展示全部能力，并为以下角色预留权限裁剪：

- 联盟总负责人：全部中心、全部模块和全部发布权限。
- 中心负责人：本中心成员、招新和业务数据。
- 内容管理员：指定内容、媒体和资源模块。

前端路由保护只负责体验和导航。真实后端接入后，每个管理读取、写入、发布、导出和下载接口都必须再次验证管理员身份和数据范围。

## 4. 首批原型页面

首批制作 15 个核心桌面页面：

1. 管理工作台。
2. 招新批次。
3. 预备成员考核台。
4. 结果发布。
5. 全体成员。
6. 成员详情。
7. 核心人员配置。
8. 荣誉审核。
9. 项目管理。
10. 活动管理与报名名单。
11. 内容管理。
12. 首页内容配置。
13. 媒体素材库与上传抽屉。
14. 学习资料与版本编辑。
15. 角色权限与操作日志。

未单独制作的页面必须复用已确认的列表、详情抽屉、编辑页、素材选择器或权限矩阵骨架，不使用空白占位页。

## 5. 工作台设计

工作台优先回答：

1. 当前有什么事情需要处理。
2. 各业务是否处于正常状态。
3. 下一步可以快速进入哪个页面。

页面结构：

- 顶部页面标题、当前批次和“新建”快捷菜单。
- 四项核心指标：待处理事项、待审核内容、待发布内容、文件存储使用情况。
- 今日待办：按风险和截止时间排序。
- 招新进度：四个中心、白泽三轮、待发布、已录取和未录取人数。
- 内容发布动态：快讯、新闻、项目和活动状态。
- 媒体与存储：图片、文件、处理中、处理失败和待审核数量。
- 最近操作记录。

指标和待办必须可点击，并跳转到带对应筛选条件的业务列表。

## 6. 页面骨架

### 6.1 列表页

统一包含：

- 页面标题和说明。
- 主要新建按钮。
- 搜索与组合筛选。
- 数据数量。
- 表格或媒体网格。
- 批量操作。
- 分页。
- 加载、错误、空数据和筛选无结果状态。

筛选条件写入 URL 查询参数，刷新和复制地址后仍可恢复。

### 6.2 详情抽屉

用于快速查看报名人员、考核信息、媒体信息、活动报名和审核摘要。

- 桌面宽度为 560px 至 620px。
- 打开时锁定背景滚动并聚焦关闭按钮。
- 支持 Escape 关闭。
- 关闭后焦点返回触发位置。
- 高风险操作不得直接在表格行内完成。

### 6.3 完整编辑页

适用于项目、活动、新闻、Banner、学习资料、成员资料和权限配置。

- 左侧或主区域为字段表单。
- 右侧为状态、影响范围、预览和发布设置。
- 提供保存草稿、提交审核、预览、发布和返回列表。
- 页面存在未保存修改时，离开前必须提示。

### 6.4 素材选择器

项目、活动、Banner、画廊和资源封面从统一媒体素材库选择：

- 只显示已处理并审核通过的素材。
- 支持搜索、类型、上传者和使用状态筛选。
- 可以在选择器内发起上传，但上传完成前不能选用。
- 同一素材可以被多个公开内容引用，不重复存储文件。

### 6.5 权限矩阵

角色权限按模块和操作拆分：

- 查看。
- 新建。
- 编辑。
- 审核。
- 发布。
- 导出。

权限修改必须展示影响范围并二次确认。

## 7. 核心业务规则

### 7.1 保存与发布分离

公开内容使用：

`编辑 → 保存草稿 → 提交审核 → 发布`

考核结果使用：

`录入内部结果 → 联盟总负责人检查 → 批量发布 → 用户结果中心可见`

保存不得自动公开，发布才改变用户端可见状态。

### 7.2 招新与考核

- 系统按第一志愿划分白泽、新媒体、拓维策划、人才发展四组。
- 白泽不按五个方向拆分名单。
- 普通中心使用一轮面试。
- 白泽必须按第一轮、第二轮、第三轮顺序推进，后续轮次不能提前编辑。
- 调剂在线下完成，系统只录入最终普通中心或未录取。
- 白泽不能成为调剂目标。
- 保存结果前展示身份、结果中心和成员关系的联动影响。
- 个人端只显示当前有效结果，不显示调剂过程、分数、内部备注或完整历史。

### 7.3 成员与公开资料

- 内部资料、公开资料、成长与荣誉分开管理。
- 公开头像与个人资料头像联动。
- 未上传或不公开时使用白底 HSD 默认头像。
- 不公开的头像原始地址不得输出到公开页面。
- 核心人员从正式成员中选择，不复制成员基础资料。
- 公开荣誉必须经过审核，并由成员选择是否公开。

### 7.4 项目、活动与内容

- 项目支持参与中心、成员、当前状态、媒体、赛事成果和首页推荐。
- 活动支持时间、地点、容量、报名截止时间、负责人和报名字段。
- 内容统一使用草稿、待审核、已发布、已下架状态。
- 首页模块结构保持固定，管理员只配置内容来源、顺序和展示数量。
- Banner 只能选择已审核素材。

### 7.5 图片与文件

真实文件不得存入数据库或 Nuxt 部署目录。后续使用对象存储保存文件，数据库保存元数据。

上传状态：

`等待上传 → 上传中 → 处理中 → 待审核 → 可使用`

失败状态必须显示原因并支持重试。

图片处理：

- 头像生成多个正方形尺寸。
- 活动、项目和画廊图片生成缩略图、中图和大图。
- 清除 EXIF 隐私信息。
- 公开页面优先使用 WebP 或其他优化格式。

学习资料：

- 支持公开、登录成员、指定中心、仅管理员四级访问范围。
- PDF 可以提供网页预览。
- DOCX、PPTX、XLSX 保留原文件，并可在后端接入后生成 PDF 预览。
- ZIP 和代码包只提供受权限保护的下载。
- 版本更新创建新版本，不直接覆盖历史文件。
- 私有下载使用短时效签名地址。

## 8. 高风险操作

以下操作必须二次确认：

- 发布考核结果。
- 修改成员身份。
- 调整中心归属。
- 下架公开内容。
- 修改管理员权限。
- 删除或恢复文件。
- 将新的学习资料版本设为当前版本。

确认窗口必须展示操作对象、变更摘要和会受影响的用户端页面。

## 9. 状态与错误处理

所有管理页面必须覆盖：

- 初始加载。
- 加载失败。
- 无数据。
- 筛选无结果。
- 编辑中。
- 保存中。
- 保存成功。
- 保存失败。
- 无权限。
- 内容已被其他管理员修改。
- 文件处理失败。
- 服务暂不可用。

错误提示必须说明原因和可执行的下一步操作。原型不以“操作失败”作为唯一信息。

## 10. 视觉与响应式

- 设计气质：同一品牌下的高密度、克制、任务导向工作台。
- 品牌关联：继续使用 HSD 深红、近黑、白和冷灰。
- 不复用官网 Banner、大型宣传图片或公开顶部导航。
- 主要验收视口：1440px。
- 兼容验收视口：1366px。
- 侧栏桌面宽度：252px。
- 顶栏高度：64px。
- 管理侧栏使用固定满高布局，顶部和底部同时贴合视口，不得在底部露出浅灰空块。
- 账号身份区固定在侧栏内部底部。
- 表格可以在自身容器内横向滚动，页面根节点不得产生横向溢出。
- 低于约 1100px 时侧栏进入紧凑模式。
- 手机管理不是首要场景，但必须可以查看数据和完成紧急操作。

## 11. 原型交互深度

首版原型必须做到：

- 七个一级导航分组可操作。
- 15 个核心页面具有完整内容结构。
- 搜索和筛选产生实际列表变化。
- 详情抽屉和编辑页面可打开。
- 上传队列展示状态变化。
- 发布、权限修改和删除展示二次确认。
- 权限矩阵可以切换角色并看到权限差异。
- Mock 数据明确标识，不声称已经写入数据库。

## 12. 测试与验收

至少验证：

- 1440px 和 1366px 页面布局。
- 侧栏始终满高。
- 页面根节点无横向溢出。
- 列表筛选、抽屉、编辑、确认和上传状态可操作。
- 管理导航不出现在公开官网。
- 普通登录成员不能因为手动输入管理路由获得真实管理权限。
- 发布前后状态在原型中有明确区分。
- 文件未接入时不生成虚假下载。
- 键盘焦点、Escape 关闭、表单标签和状态提示可访问。

## 13. 本阶段不实现

- 真实后端 API。
- 真实数据库写入。
- 对象存储直传。
- 图片压缩服务。
- Office 转 PDF。
- 病毒扫描。
- 真实 RBAC 权限校验。
- 真实短信、邮件或站内通知。
- 活动签到。
- 自动化调剂流程。

这些能力只在原型中展示入口、字段、状态和影响范围，不伪装为已接入。
