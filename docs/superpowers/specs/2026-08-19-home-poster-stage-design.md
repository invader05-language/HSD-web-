# 首页沉浸式双层海报舞台设计

## 目标

改善首页右侧竖版海报当前占比过小、留黑过多、像普通占位框的问题，在不牺牲海报完整信息的前提下，建立更有层次的主视觉。

## 已确认方案

采用“沉浸式双层海报舞台”：同一张首页视觉海报同时承担氛围背景和信息前景两个层次。

- 背景层使用海报放大铺满右侧舞台，允许裁切。
- 背景层降低亮度和饱和度，叠加深红至炭黑渐变蒙版，弱化重复图案。
- 前景层继续完整显示海报，不裁切，扩大到舞台高度的约 88%–92%，略向右偏移。
- 前景层使用宽范围柔和阴影和轻微边缘高光，形成悬浮的印刷品层次。
- 移除右侧的大面积无意义留黑和原有机械分隔感，但保留首页左侧红色品牌文案区。

## 响应式规则

- 桌面端主视觉保持现有左右结构，Hero 高度保持在 480px 左右，前景海报占右侧舞台主要高度。
- 移动端恢复上下布局，背景氛围层仍存在但更暗，完整海报宽度控制在视口 72%–82%，禁止横向溢出。
- 后台上传的首页媒体仍优先于默认素材；无上传媒体时使用当前受控默认海报。

## 约束与非目标

- 不裁切前景海报，不重写首页文案、按钮和快讯结构。
- 不增加玻璃拟态、装饰光球、复杂动画或额外运营文案。
- 不修改其他页面封面图片。

## 验收标准

1. 首页默认海报在桌面端明显扩大，背景层填充右侧区域，前景海报完整可读。
2. 首页默认海报在移动端完整显示且页面无横向滚动。
3. 配置了后台上传媒体时仍展示上传媒体，不被默认背景层覆盖。
4. 图片加载、首页布局和现有单元测试、端到端测试全部通过。
